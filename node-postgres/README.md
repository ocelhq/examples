# node-postgres

An Express 5 notes API on a Postgres database that exists because the code says `postgres("main")`.

## Run it

```bash
pnpm install
ocel dev
```

```bash
curl -X POST localhost:$PORT/notes -H content-type:

## Deploy it

```bash
ocel deploy
```

`ocel destroy` takes it down again.

## How it works

application/json -d '{"body":"hello"}'
curl localhost:$PORT/notes
```

`$PORT` is whatever port `ocel dev` prints.
